# Ngọc Châu – Jewelry Shop Website

Chào mừng bạn đến với dự án website cửa hàng trang sức cao cấp **Ngọc Châu**. Đây là một giao diện website sang trọng, tinh tế, được thiết kế để tôn vinh di sản từ năm 1968 của thương hiệu trang sức từ Hải Dương - tọa lạc tại 82 Hàng Bồ, Hà Nội.

## 📦 Cài đặt
Dự án được xây dựng dưới dạng trang web tĩnh (Static Site), không cần cài đặt phức tạp.

1. Clone repository hoặc tải thư mục dự án về máy.
2. Bạn có thể mở trực tiếp file `index.html` trên trình duyệt hoặc sử dụng các trình chạy web server đơn giản như Live Server (VS Code).

## 🚀 Khởi chạy
- Mở file `index.html` trong trình duyệt web của bạn.
- Truy cập qua localhost nếu bạn sử dụng dev server (ví dụ: `http://localhost:5500`).

## 📐 Công nghệ sử dụng
- **HTML5**: Cấu trúc ngữ nghĩa (Semantic HTML) và chuẩn SEO.
- **CSS3**: Sử dụng biến (CSS Variables), Flexbox, Grid, và các hiệu ứng animation hiện đại (Glassmorphism, Scroll Reveal).
- **Javascript (Vanilla)**: Xử lý các tương tác người dùng, menu mobile, hiệu ứng cuộn trang và giỏ hàng.
- **Font Awesome & Google Fonts**: Montserrat & Playfair Display cho phong cách sang trọng.

## ✨ Tính năng nổi bật
- **Responsive hoàn hảo**: Hiển thị đẹp mắt trên máy tính, máy tính bảng và điện thoại di động.
- **Hiệu ứng sang trọng**: Các phần tử fade-in mượt mà khi cuộn trang, hình ảnh sản phẩm thay đổi khi hover (2 mặt).
- **Bộ lọc sản phẩm**: Giao diện bộ lọc chuyên nghiệp trên sidebar (Desktop) và nút bật tắt trên Mobile.
- **Giỏ hàng & Liên hệ**: Hệ thống cập nhật giỏ hàng nhanh và form liên hệ đã được tích hợp logic.

## 🧪 Test & Demo (Tự động)

2. Kiểm tra giao diện Mobile.
3. Quay video hiệu ứng scroll.
